# Restoran

Restoran siparişlerini tutan Windows uygulaması.

## Ne var

Ekranlar `Restorant` projesindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Windows Forms ve DataSet.
